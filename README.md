# Descripcion del proyecto
Este es el Back del proyecto de KickHeadz , el cual ayuda a la funcionalidad de la app
Hecho con lenguaje de javascript , node.js , express y autenticación con JTW

# Descripción de las carpetas
Las carpetas principales dentro de "src" , son los modulos que contiene las rutas y controladores 
La DB donde estan los modelos y el archivo mysql para hacer la conexión con la BD
La carpeta de red donde se encuentran las respuestas

# Instrucciones de arranque 
Descargar el repositorio
Añadir las variables de entorno (Ver archivo config.js donde se muestran las variables necesarias) 
Usar " npm install " desde carpeta raiz 
Despues usar " npm run dev " desde carpeta raiz
